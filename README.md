## Abstract

This research presents the design and implementation of a low-cost, flexible, multi-shuttle Automated Storage and Retrieval System (ASRS) utilizing Quick Response Codes (QR codes) as the primary identification medium. To minimize hardware costs while maintaining robust system capabilities, all operations—including website hosting, motor control, and camera-based vision detection—were integrated into a single-board computer (Raspberry Pi) using Python multithreading and multiprocessing architectures. 

The system incorporates a Warehouse Management System (WMS) featuring an OpenCV-powered Graphical User Interface (GUI) and a real-time Django web dashboard connected to a MySQL database. This setup allows users to execute automated inbound/outbound processes, track real-time storage inventory, and monitor operations remotely. Designed with high scalability, the ASRS structure can easily expand without modifying existing architecture, making it applicable to unmanned stores, e-commerce facilities, and large-scale logistics warehouses.
